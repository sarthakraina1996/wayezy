# Wayezy

3D wayfinding for malls and venues by BrainADZ Live: in-mall kiosk, phone app and admin hub.

Open `index.html?view=kiosk`, `?view=app` or `?view=admin`. This is the static demo (sample data, kept on each visitor's device); it is built from the Wayezy project with `python web/build_static_site.py`.
